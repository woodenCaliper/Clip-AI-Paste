Privacy Policy — Clip AI Paste

Last updated: 2026-05-08

Data Collection

Clip AI Paste does not collect, store, or transmit any personal data to the developer.

Clipboard Data

Clipboard text is read only when the user triggers the shortcut key. It is sent directly to the AI provider selected by the user (OpenAI, Google Gemini, or Anthropic Claude). The developer does not receive or store this data.

API Keys

API keys entered by the user are stored locally in chrome.storage.sync. They are used solely to authenticate requests to the selected AI provider. They are never sent to the developer's servers.

Contact

For questions, please open an issue on GitHub: https://github.com/woodenCaliper/Clip-AI-Paste/issues

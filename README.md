# Clip AI Paste

`Clip AI Paste` は、**ショートカット1回**で以下を実行する Chrome 拡張です。

1. クリップボードのテキストを読む
2. 設定した指示プロンプトと結合して AI に送る
3. AI の回答をクリップボードへ上書きする
4. 現在の入力先へ自動で貼り付ける

> 想定用途: ローカルで自分だけが使う個人ユース

---

## 機能

- 対応 AI プロバイダ
  - OpenAI
  - Gemini
  - Claude
- 1つのショートカットで実行（初期値: `Ctrl+B`）
- 指示プロンプトは1つ（設定画面で編集）
- 設定画面で「最終送信プロンプト」のプレビュー確認
- AI ごとに API キーとモデル名を設定可能
- 10秒タイムアウト
- エラー通知（Chrome 通知）
- 実行中表示（拡張バッジ）

---

## インストール（ローカル読み込み）

1. このリポジトリをローカルに配置
2. Chrome で `chrome://extensions` を開く
3. 右上の **デベロッパーモード** を ON
4. **パッケージ化されていない拡張機能を読み込む** をクリック
5. このフォルダ（`manifest.json` があるフォルダ）を選択

---

## 初期設定

1. 拡張機能の詳細画面から **拡張機能のオプション** を開く
2. 以下を入力して保存
   - 使用AI（OpenAI / Gemini / Claude）
   - 各 API キー
   - 各モデル名
   - 指示プロンプト
3. 設定画面のプレビュー欄で、AIへ送る最終プロンプト形式を確認
4. 必要なら `chrome://extensions/shortcuts` でショートカットを変更

---

## 使い方

1. 変換したいテキストをクリップボードに入れる（コピー）
2. テキスト入力欄（input / textarea / contenteditable）にカーソルを置く
3. ショートカット（初期値: `Ctrl+B`）を押す
4. AI 応答が自動で貼り付けられる

---

## 送信フォーマット

AI には次の形式で送信します。

```text
"入力テキスト"の内容に対して下記の指示を適用してください

# 指示
{指示プロンプト}

# 入力テキスト
{クリップボード本文}
```

---

## 注意事項

- クリップボードが空、または空文字テキストの場合は何もしません。
- 元のクリップボード内容は復元しません（AI回答で上書きされます）。
- ブラウザやページの制約により、貼り付け挙動が一部ページで異なる可能性があります。
- API キーは `chrome.storage.sync` に保存されます。取り扱いには注意してください。

---

## トラブルシュート

- **APIキー未設定エラー**
  - オプション画面で、選択中 AI の API キーが入っているか確認
- **タイムアウト（10秒）**
  - モデル変更、入力短縮、ネットワーク状態を確認
- **貼り付けされない**
  - 入力欄にフォーカスがあるか確認
  - 権限制約の強いページ（ブラウザ内部ページ等）では動作しない場合があります

## リリース運用ルール（バージョン管理）

### バージョニング方針（SemVer準拠）

`manifest.json` の `version` は **Semantic Versioning（MAJOR.MINOR.PATCH）** で管理します。

- **MAJOR**: 破壊的変更（既存の設定・操作互換を壊す変更）
- **MINOR**: 後方互換ありの機能追加
- **PATCH**: 後方互換ありのバグ修正・文言修正

例:
- `1.4.2` → `1.4.3`（軽微な不具合修正）
- `1.4.2` → `1.5.0`（新機能追加）
- `1.4.2` → `2.0.0`（互換性に影響する仕様変更）

### `manifest.json` の `version` 更新手順

1. 変更内容を分類し、MAJOR / MINOR / PATCH を決定する。
2. `manifest.json` の `version` をインクリメントする。
3. 変更概要テンプレート（下記）を更新して、レビュー・審査提出文に流用する。
4. ローカルで再読み込みし、主要フロー（起動・ショートカット・API呼び出し・貼り付け）を確認する。
5. ストア提出時のチェックリストを満たしていることを確認する。

変更箇所:
- `manifest.json` の `"version"` フィールド

### ストア提出時チェックリスト

- [ ] `manifest.json` の `version` が前回提出版より増加している
- [ ] ストア説明文と実装差分に矛盾がない
- [ ] 追加/変更した機能がユーザー向け説明に反映されている
- [ ] 権限（`permissions` / `host_permissions`）差分を確認済み
- [ ] 新規権限を追加した場合、審査向け説明文に「必要性・利用場面・最小権限である理由」を明記した
- [ ] アイコン、名称、スクリーンショット等のストア素材が最新仕様と一致している
- [ ] エラーハンドリング（通知文言含む）が過度に曖昧でない

### 審査再提出時の注意点（特に権限追加時）

審査差し戻し後に再提出する際は、前回からの差分説明を簡潔に記載します。特に権限追加がある場合は、以下を強化してください。

- **追加した権限ごとに用途を1対1で説明**する
- **ユーザー操作起点（いつ使われるか）**を具体化する
- **取得データと保存範囲**（一時利用か、保存するか）を明記する
- **最小権限原則**（より広い権限を使っていない理由）を記載する
- 可能なら「権限未許可時に機能を無効化する挙動」も説明する

推奨: 審査コメントには「前回指摘への対応内容」を箇条書きで先頭に置く。
